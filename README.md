# Projeto Educacional e Integrador — Formação Integrada

Repositório educacional para documentação, acompanhamento e orientação de projetos interdisciplinares desenvolvidos por estudantes da **Formação Integrada** (Ensino Médio + Técnico em Informática para a Internet).

## Objetivo

Promover a integração entre o ensino médio e a formação técnica através de projetos práticos, desenvolvendo competências em **desenvolvimento Web, aplicações móveis, banco de dados, engenharia de software, UX/UI e mentalidade tecnológica**, aproximando escola, comunidade e mercado.

## Etapas de Orientação

1. **Definição do problema** — identificação de necessidades do cotidiano escolar ou comunitário
2. **Requisitos e modelagem** — levantamento de funcionalidades, UX/UI, modelo de dados
3. **Desenvolvimento** — Front-end Web, aplicações móveis, banco de dados
4. **Testes** — validação, correção de bugs, ajustes
5. **Documentação** — README, manual de uso, apresentação
6. **Apresentação e avaliação** — demo, feedback e entrega final
