# Rubrica de Avaliação — Projeto Integrador (Formação Integrada)

| Critério | Peso | Excelente (10) | Bom (7-9) | Regular (5-6) | Insuficiente (<5) |
|---|---|---|---|---|---|
| Definição do problema | 15% | Problema claro, relevante e validado | Problema definido | Problema vago | Sem definição |
| Requisitos e modelagem | 15% | Requisitos completos e modelagem documentada | Requisitos básicos | Requisitos parciais | Sem requisitos |
| Desenvolvimento Web/Mobile | 25% | Código limpo, responsivo e funcional | Código funcional | Código com bugs | Sem implementação |
| UX/UI e acessibilidade | 10% | Interface intuitiva, responsiva e acessível | Interface adequada | Interface simples | Sem cuidado visual |
| Trabalho colaborativo (Git) | 10% | Commits frequentes, uso de branches | Commits regulares | Poucos commits | Sem versionamento |
| Mentalidade tecnológica | 10% | Autonomia, resolução de problemas e iniciativa | Boa autonomia | Pouca autonomia | Sem autonomia |
| Documentação | 5% | Documentação completa e clara | Documentação básica | Documentação mínima | Sem documentação |
| Apresentação | 10% | Apresentação clara, demo funcional | Apresentação adequada | Apresentação incompleta | Sem apresentação |
