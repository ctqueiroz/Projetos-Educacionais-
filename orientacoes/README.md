# Orientações para Estudantes

## Primeiros Passos
1. Forme sua equipe (2 a 4 integrantes)
2. Identifiquem um problema do cotidiano escolar ou comunitário
3. Definam a plataforma: Web, Mobile ou ambos
4. Crie um repositório no GitHub para o projeto
5. Preencha o template de escopo (`templates/escopo-projeto.md`)
6. Compartilhe o link do repositório com o orientador

## Durante o Projeto
- Faça commits frequentes (mínimo 1x por semana)
- Mantenha o README atualizado com instruções de instalação
- Documente decisões importantes
- Use branches para novas funcionalidades
- Teste antes de fazer merge
- Dividam as tarefas entre a equipe
- Pesquisem soluções antes de perguntar — desenvolvam autonomia

## Entrega Final
- README completo com instruções de instalação e uso
- Apresentação de 10-15 minutos
- Demo funcional do sistema (Web e/ou Mobile)
- Código versionado e organizado
- Todos os integrantes devem participar da apresentação

## Git e GitHub
- Um integrante cria o repositório
- Convida os demais como colaboradores (Settings → Collaborators)
- Usem mensagens de commit descritivas
- Exemplo: `feat: adiciona tela de login`
- Exemplo: `fix: corrige erro de validação de senha`

## Mentalidade Tecnológica
- **Não tenham medo de errar** — o erro faz parte do processo
- **Pesquisem antes de perguntar** — Google, Stack Overflow, documentação
- **Compartilhem conhecimento** com a equipe
- **Pensem no usuário** — a tecnologia existe para resolver problemas reais
- **Sejam curiosos** — explorem novas ferramentas e tecnologias
