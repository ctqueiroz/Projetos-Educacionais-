# Projetos de Referência

Projetos de exemplo para inspirar e orientar estudantes do **Projeto Integrador — Formação Integrada (Técnico em Informática para a Internet)**.

---

## 📋 Como usar os exemplos

1. **Não copie** — use como referência de escopo, estrutura e qualidade
2. Leia o README de cada exemplo para entender o problema e a solução
3. Observe como o código está organizado (pastas, commits, documentação)
4. Use como modelo para sua própria documentação e apresentação
5. Adapte a ideia ao seu contexto — não replique o mesmo projeto

---

## 🌐 Projetos Web

### 1. Portal de Eventos Escolares
**Plataforma:** Web  
**Tecnologias:** HTML, CSS, JavaScript, Node.js, MySQL  
**Problema:** A escola divulga eventos em cartazes e grupos de WhatsApp, gerando informação dispersa  
**Solução:** Portal centralizado com calendário, inscrições online e notificações  
**Aprende-se:** CRUD, autenticação, responsividade, integração com banco de dados

### 2. Sistema de Gestão de Tarefas
**Plataforma:** Web  
**Tecnologias:** React, Node.js, SQLite  
**Problema:** Estudantes não têm um sistema simples para organizar tarefas escolares por disciplina  
**Solução:** App de tarefas com categorias por disciplina, prazos e status  
**Apreende-se:** SPA (Single Page Application), estado global, filtros, drag-and-drop

### 3. Site de Biblioteca Escolar
**Plataforma:** Web  
**Tecnologias:** HTML, CSS, JavaScript, PHP, MySQL  
**Problema:** A biblioteca da escola não tem sistema online para consulta de acervo  
**Solução:** Site com busca de livros, reserva online e histórico de empréstimos  
**Apreende-se:** Consulta SQL, paginação, sessões, design de interface

## 📱 Projetos Mobile

### 4. App de Cardápio da Cantina
**Plataforma:** Mobile  
**Tecnologias:** React Native, Firebase  
**Problema:** Estudantes não sabem o cardápio do dia antes de irem para a cantina  
**Solução:** App com cardápio diário, notificações e avaliação de pratos  
**Apreende-se:** Navegação mobile, consumo de API, push notifications, Firestore

### 5. App de Frequência Escolar
**Plataforma:** Mobile  
**Tecnologias:** React Native, Node.js, SQLite  
**Problema:** Professores registram frequência em papel, sem visibilidade para a coordenação  
**Solução:** App com leitura de presença por turma, relatórios e alertas de faltas  
**Apreende-se:** CRUD mobile, relatórios, gráficos, autenticação por perfil

### 6. App de Flashcards Educativos
**Plataforma:** Mobile  
**Tecnologias:** React Native, Firebase  
**Problema:** Estudantes precisam de uma ferramenta de revisão por disciplina  
**Solução:** App de flashcards com baralhos por disciplina, modo revisão e estatísticas  
**Apreende-se:** Estado local, persistência, animações, gamificação

## 🎮 Projetos Interdisciplinares

### 7. Jogo Educativo Web — Quiz de Ciências
**Plataforma:** Web  
**Tecnologias:** HTML, CSS, JavaScript, Canvas API  
**Problema:** Estudantes do fundamental têm dificuldade com conteúdo de ciências  
**Solução:** Jogo de quiz interativo com pontuação, fases e ranking  
**Apreende-se:** Lógica de jogo, Canvas, armazenamento local, animação

### 8. Portfólio Digital Turma
**Plataforma:** Web  
**Tecnologias:** HTML, CSS, JavaScript, GitHub Pages  
**Problema:** A turma não tem um espaço para mostrar projetos e atividades do semestre  
**Solução:** Site coletivo com seções por disciplina, galeria de projetos e depoimentos  
**Apreende-se:** Design responsivo, deploy no GitHub Pages, trabalho colaborativo

### 9. Sistema de Agendamento de Recursos Escolares
**Plataforma:** Web + Mobile  
**Tecnologias:** React, React Native, Node.js, MySQL  
**Problema:** Laboratórios e salas não têm sistema de reserva, gerando conflitos de horário  
**Solução:** Sistema de agendamento com calendário, aprovação e confirmação  
**Apreende-se:** Full-stack, API REST, autenticação por perfil, notificações

## 📊 Avaliação dos exemplos

Cada projeto de referência deve conter:

| Item | Descrição |
|---|---|
| 📝 README completo | Problema, solução, funcionalidades, tecnologias, instruções |
| 🗂️ Código organizado | Estrutura de pastas clara, commits descritivos |
| 🎨 UX/UI | Interface responsiva e acessível |
| 🗄️ Banco de dados | Modelagem documentada (DER) |
| 📸 Screenshots | Telas principais do sistema |
| 🎥 Demo | Link de vídeo ou deploy online |
| 📄 Documentação | Manual de instalação e uso |

## 💡 Como propor um novo exemplo

1. Identifique um problema real do cotidiano escolar ou comunitário
2. Verifique se a solução é viável com as tecnologias do curso
3. Considere a complexidade adequada para a formação integrada
4. Documente o problema, a solução e as tecnologias
5. Desenvolva um protótipo funcional
6. Adicione como exemplo neste arquivo com a estrutura acima
