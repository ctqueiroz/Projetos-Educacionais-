# Projetos dos Estudantes

Repositório central para registro e acompanhamento dos projetos desenvolvidos pelos estudantes orientados no **Projeto Integrador — Formação Integrada (Técnico em Informática para a Internet)**.

---

## Como adicionar seu projeto

1. Crie um repositório no GitHub para o projeto da sua equipe
2. Garanta que o repositório seja **público**
3. Envie o link para o orientador com:
   - Nome da equipe
   - Nome do projeto
   - Integrantes
   - Link do repositório
4. O orientador adicionará o projeto na tabela do semestre correspondente

## Acompanhamento

O acompanhamento semanal é feito via **GitHub Projects** deste repositório. Cada equipe é representada por um issue no quadro Kanban:

**Backlog** → **Definição do problema** → **Requisitos & Modelagem** → **Em desenvolvimento** → **Testes & Documentação** → **Entregue**

> **Pipeline de Status:**
> 📋 Em Requisitos → 🟡 Em Modelagem → 🟢 Em Desenvolvimento → 🧪 Em Teste → ✅ Entregue → 🏆 Aprovado
